# صيّاد الأسعار — Sayyad Prices

مشروع بداية لتطبيق عربي لمتابعة أسعار المنتجات على Android وiPhone باستخدام Flutter.

## الموجود في هذه النسخة
- واجهة عربية RTL.
- شاشة رئيسية تعرض المنتجات المتابعة.
- إضافة منتج برابط متجر وسعر مستهدف ومقاس اختياري.
- شاشة تفاصيل مبسطة مع سجل أسعار تجريبي.
- صفحة الباقات (مجانية / Basic / Pro) بتصميم توضيحي.
- بيانات تجريبية محلية للتجربة.

## مهم قبل الإطلاق
هذه **نسخة مصدر أولية قابلة للتطوير وليست تطبيقًا منشورًا أو خدمة مراقبة أسعار عاملة**.
لا يتم جلب أسعار المتاجر تلقائيًا بعد. يلزم:
1. Backend مستضاف وجدولة مهام دورية.
2. تكامل قانوني ومستقر مع مصادر الأسعار لكل متجر (واجهات API أو مزود بيانات مصرح به). لا تعتمد على كسر الحماية أو تجاوز قيود المواقع.
3. قاعدة بيانات وحسابات مستخدمين.
4. خدمة إشعارات Push (مثل Firebase Cloud Messaging).
5. اشتراكات داخل التطبيق عبر Apple In-App Purchase وGoogle Play Billing، مع الالتزام بسياسات المتجرين.
6. اختبار على أجهزة حقيقية، ثم حسابات مطورين ونشر رسمي.

## التشغيل
يتطلب Flutter SDK وDart:
```bash
flutter create sayyad_prices
# انسخ مجلد lib من هذا المشروع إلى sayyad_prices/lib
flutter pub get
flutter run
```

## إعدادات مستقبلية
- ضع عنوان API في `lib/config/app_config.dart`.
- لا تضع مفاتيح سرية داخل تطبيق الهاتف.
- استخدم HTTPS وخزّن أسرار المتاجر على الخادم فقط.

## ملاحظة التسعير
الأسعار المقترحة في صفحة الباقات مجرد أمثلة قابلة للتعديل وليست أسعارًا معتمدة أو اشتراكات مفعلة.
